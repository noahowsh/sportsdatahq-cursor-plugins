# YorkerAPI for Cursor

Cricket ball by ball in every format, men's and women's: scorecards, matchups, ratings, win probability and match prices.

Adds the YorkerAPI MCP server (`https://mcp.yorkerapi.com/mcp`) to Cursor. On first use Cursor opens a YorkerAPI sign-in page; sign in or create a free account (500 credits a month, no card) and press Allow.

Docs: https://yorkerapi.com/docs
