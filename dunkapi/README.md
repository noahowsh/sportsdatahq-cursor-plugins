# DunkAPI for Cursor

NBA, WNBA and college basketball: play-by-play with every shot located, box scores, team ratings, injuries and odds.

Adds the DunkAPI MCP server (`https://mcp.dunkapi.com/mcp`) to Cursor. On first use Cursor opens a DunkAPI sign-in page; sign in or create a free account (500 credits a month, no card) and press Allow.

Docs: https://dunkapi.com/docs
