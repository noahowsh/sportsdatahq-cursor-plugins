# FighterAPI for Cursor

Every UFC fight since 2000: results, stat sheets, round-by-round stats, fighter profiles, ratings and odds.

Adds the FighterAPI MCP server (`https://mcp.fighterapi.com/mcp`) to Cursor. On first use Cursor opens a FighterAPI sign-in page; sign in or create a free account (500 credits a month, no card) and press Allow.

Docs: https://fighterapi.com/docs
