# PuckAPI for Cursor

NHL and PWHL data: play-by-play with coordinates, shifts, shot maps, expected goals, goalie and skater stats, standings and odds.

Adds the PuckAPI MCP server (`https://mcp.puckapi.com/mcp`) to Cursor. On first use Cursor opens a PuckAPI sign-in page; sign in or create a free account (500 credits a month, no card) and press Allow.

Docs: https://puckapi.com/docs
