# FastballAPI for Cursor

MLB since 2015: every pitch and plate appearance, win probability, run value, spray charts, box scores and odds.

Adds the FastballAPI MCP server (`https://mcp.fastballapi.com/mcp`) to Cursor. On first use Cursor opens a FastballAPI sign-in page; sign in or create a free account (500 credits a month, no card) and press Allow.

Docs: https://fastballapi.com/docs
