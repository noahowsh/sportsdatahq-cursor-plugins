# StrikerAPI for Cursor

17 soccer leagues: results, lineups, every event, shots with location and xG, tables, ratings and odds.

Adds the StrikerAPI MCP server (`https://mcp.strikerapi.com/mcp`) to Cursor. On first use Cursor opens a StrikerAPI sign-in page; sign in or create a free account (500 credits a month, no card) and press Allow.

Docs: https://strikerapi.com/docs
