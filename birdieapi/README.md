# BirdieAPI for Cursor

PGA Tour leaderboards and hole-by-hole scores since 2001, plus the LPGA, LIV, DP World and Korn Ferry tours.

Adds the BirdieAPI MCP server (`https://mcp.birdieapi.com/mcp`) to Cursor. On first use Cursor opens a BirdieAPI sign-in page; sign in or create a free account (500 credits a month, no card) and press Allow.

Docs: https://birdieapi.com/docs
