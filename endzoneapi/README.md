# EndzoneAPI for Cursor

NFL data since 1999: play-by-play with EPA and win probability, weekly player stats, injuries, depth charts, snap counts and odds.

Adds the EndzoneAPI MCP server (`https://mcp.endzoneapi.com/mcp`) to Cursor. On first use Cursor opens a EndzoneAPI sign-in page; sign in or create a free account (500 credits a month, no card) and press Allow.

Docs: https://endzoneapi.com/docs
