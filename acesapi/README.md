# AcesAPI for Cursor

ATP and WTA singles since 2007: every set and tiebreak, draws, weekly rankings, head to head, surface Elo and odds.

Adds the AcesAPI MCP server (`https://mcp.acesapi.com/mcp`) to Cursor. On first use Cursor opens a AcesAPI sign-in page; sign in or create a free account (500 credits a month, no card) and press Allow.

Docs: https://acesapi.com/docs
